# Éclat

Course infinie dans un couloir de verre néon, jouable au doigt sur mobile. Un seul fichier : `index.html`.

## Jouer

- Ouvre `index.html` dans un navigateur (mobile ou desktop), ou active GitHub Pages sur ce dépôt.
- **Touche** l'écran : lance un orbe là où tu vises. Chaque lancer coûte 1 orbe.
- **Maintiens** : le temps ralentit (jauge Focus). Relâche : tir **Prisme** qui traverse les vitres et explose.
- **Cristal doré** : +3 orbes (+4 en combo ≥ 8). **Cristal bleu** : recharge le Focus.
- Une vitre prise de face coûte 10 orbes. Plus d'orbes : fin de partie.
- Combo ≥ 8 : orbes en surchauffe (petite explosion). Combo ≥ 20 : fusion (grosse explosion).
- Tous les 650 m, une nouvelle zone change la palette et la musique.

Tout est généré par le code : géométrie, textures, sons et musique (Web Audio). Seule dépendance : Three.js r128 via cdnjs.
